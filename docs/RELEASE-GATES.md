# 1.0 release acceptance criteria

A scholarly **text-level** 1.0 requires all of:

- [x] Stable preliminary segment identifiers and source bibliography
- [x] Distinguish segments from physical monuments
- [x] Dedicated research AI skill and master registry membership (provisional)
- [x] Machine-readable record schema and source-specific rights policy
- [ ] Edition-verified diplomatic readings and normalized transliterations for TL 44c, TL 44d, TL 55
- [ ] Line-level provenance, editorial uncertainty and competing readings reconciled
- [ ] Legal review for redistributed source-derived text and images
- [ ] Automated schema and semantic tests executed against committed data
- [ ] Full shared corpus-factory contract and master skill bundle freshness validation
- [ ] Researcher reproducibility check and human review handoff

Current readiness: **NOT READY FOR SCHOLARLY 1.0**. No verified transcriptions are available in this repository. A package may be structurally complete without claiming text-level completeness.
